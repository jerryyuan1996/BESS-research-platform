# BESS Research Platform：投资人视角评审与修改建议

评审日期：2026年10月30日（澳大利亚珀斯时间）
网站：[Global BESS](https://globalbess.vercel.app/)
仓库：[jerryyuan1996/BESS-research-platform](https://github.com/jerryyuan1996/BESS-research-platform)
初次评审基线：PR #67，提交 b56738e。更新复核基线：[PR #68](https://github.com/jerryyuan1996/BESS-research-platform/pull/68)，已合并至 main，提交 [cfe29c5](https://github.com/jerryyuan1996/BESS-research-platform/commit/cfe29c5fe4bba956c8d6ccddfe5247bbc75143bc)。下文前十二部分保留初次评审证据；第十三部分补充18个市场的新情况与本轮实施范围。

**总体判断：网站已经具备“投资筛选平台”的雏形，研究深度也足以支撑严肃讨论。下一阶段最有价值的工作，是让推荐结论、投资情景、数字、风险和行动始终对应同一件投资。** 当前适合市场初筛、形成研究议程和比较投资路径；直接用于投委会讨论时，仍需人工解释若干口径冲突。

这次更新最明显的进步，是形成了“投资简报 → 全球比较 → 市场详情”的主线，并开始用统一的税后投资模型、融资情景和特殊机会对比回答资本配置问题。阅读中的主要阻力集中在三个方面：一些旧文字仍在解释新数字；市场层面的吸引力与具体项目的可投资条件混在一起；决定投资的否决条件和下行结果出现得偏晚。

本文将已确认的展示问题、需要改善的投资表达、建议新增的交互分开说明。表中数值用于识别网站内部的一致性问题，不代表对各国法规、收入预测或银行条款逐项重新核验。

**核查范围与方法。** 已通过 GitHub 核对最新合并和现行实现，并线上阅读首页、全球比较、意大利、德国、芬兰、波兰、西澳、爱尔兰市场详情，以及新闻和数据页面；对首页与全球比较做了桌面截图检查。其余市场通过全部15份市场观点文件、共用页面逻辑，以及安大略和各市场深层研究章节的源文案进行交叉检查。投资分析工具、观察名单、变更记录和分析师工作台检查了路由、页面实现及文案。本文不将源代码检查表述为所有页面都完成了浏览器视觉验收；手机、打印、全部折叠面板及每个市场的所有深层标签仍应纳入实施后的验收。

**一、应当保留并强化的部分**

1. **三层主线成立。** 首页回答优先研究什么，比较页回答机会之间如何取舍，市场页回答为什么成立、如何落地。这个骨架适合投资人，不需要重新推倒。
2. **研究不是单纯罗列市场数据。** 英国对交付位置和收入压缩的分析、罗马尼亚对“补助降低资本投入但不等于锁定收入”的区分、日本对区域差异和双向并网能力的强调，都有投资价值。
3. **已有很多融资与尽调能力。** 收入分层、收购价格上限、建设前资金、合同证据、下行场景和来源登记均已存在。主要任务是把决定结论的部分移到读者看得到的位置，并统一口径。
4. **统一投资模型方向正确。** 将20年税后名义全股权持有回报作为主指标，同时披露杠杆后股权回报、出售检验和可支付价格，较容易与投资人的讨论方式衔接。
5. **特殊机会开始回答“价值来自哪里”。** 并网时间、成本、合同和额外权利对价可以进入同一比较，这是网站区别于普通市场报告的重要能力。
6. **视觉基调合适。** 纸色背景、深绿色和较克制的排版有研究简报的感觉。优先改善信息层级、可读性和图表含义，保持当前风格。

**二、优先修正：同一个投资结论必须使用同一套数字**

**P0-01：市场页开头的回报文字与主回报卡存在冲突。**

这不是需要重新解释的合理模型差异，而是不同口径在同一个决策页面上没有得到充分隔离。

| 市场与视角 | 页面开头或旧观点中的数字 | 现行主回报显示 | 对投资人的影响 |
|---|---|---|---|
| 意大利，基础设施基金 | 最佳设计、持有期回报14.6% | 全股权长持11.6% | 最先读到的投资论点夸大了当前页面所展示的回报 |
| 德国，基础设施基金 | 五年租赁11.7%，纯市场化13.9% | 当前租赁方案全股权长持9.1% | 比较优势和是否达标都可能被误读 |
| 芬兰，基础设施基金 | 持有期14.6%，首年一半收入锁定 | 主回报14.9%；比较页模型固定收入40% | 数字差异与保底条件差异同时存在 |
| 波兰，基础设施基金 | 获补助四小时市场化设计17.1% | 全股权长持11.5% | 可能把尚未达标的情景读成高回报机会 |

主页面已在展开说明中解释旧版15年税前运营模型，但读者通常先相信页面上方的论点。说明藏在后面不能消除前面的冲突。

**建议修改：**

- 将当前方案中的回报、固定收入比例、投资额、目标回报、COD和收入资格时间改为同一情景结果的引用。
- 观点文字保留“为什么投、为什么暂缓、什么会推翻判断”；可计算数字由当前模型填入，避免在观点文件中重复维护。
- 给每个展示结果绑定市场、投资者类型、路径、储能时长、进入阶段、模型版本及数据日期。
- 旧运营模型仍可用于历史解释，但应明确标为“历史研究口径”，默认折叠，并列出与当前投资模型的差别。
- 同时清理深层研究中“回报为所有市场之最”“四个市场中最低”等随比较样本和模型更新而失效的文字。

**验收标准：** 同一投资者和方案下，首页、比较表、市场论点、回报卡、收益图、特殊机会常规列及导出结果完全对账；历史模型的差异在看到数字时就能辨认。

证据：[意大利](https://globalbess.vercel.app/markets/italy)、[德国](https://globalbess.vercel.app/markets/germany)、[芬兰](https://globalbess.vercel.app/markets/finland)、[波兰](https://globalbess.vercel.app/markets/poland)。实现中，开头文字读取静态 play.why，主回报读取新的投资汇总，见[页面实现第264行](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/experience/pages.js#L264)。

**P0-02：芬兰固定收入比例在同页内也不一致。**

线上所见：全球比较的固定收入为40%；芬兰收益拆解旁的比例为50%；同一收益图固定收入约USD 46.1k/MW，总收入约USD 115.2k/MW，两者相除约40%。

这说明问题不只发生在文字段落。收益图读取新投资模型，旁边的比例仍读取旧模型。

**建议修改：**

- 先确认当前推荐方案究竟要求“预期收入一半的保底”，还是采用现行模型约40%的首年固定比例；两者不能未经解释同时保留。
- 固定比例始终由该图的固定收入除以同一口径总收入计算。
- 明确比例的分母是毛收入、扣优化费用后收入还是经营现金流。
- 将“首年比例”和“全寿命收入保护程度”分开，说明保底期限及到期后的处理。

**验收标准：** 同页百分比可以用图上的金额复算；修改保底金额、合同期限或交易收入后，相关文字和图表同步更新。

证据：[页面实现第342–347行](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/experience/pages.js#L342)，其中比例仍使用 data.base.securedShare。

**P0-03：推荐进入阶段与主回报的计算起点应当同时说清楚。**

现有展示可能在推荐路径中写“绿地开发”“共同投资”或“在运资产”，旁边却给出统一RTB交割起点的新建投资回报。比较页已有部分“新建情景”说明，这是进步，但字号和位置不足以承载这一关键区别。

例如，战略投资者看西澳时，绿地开发标签容易让人以为主回报已涵盖RTB之前的开发投入、失败概率和等待时间；在运收购方案旁的新建IRR，又容易被误当作实际收购收益率。

此外，参考测算默认收购对价为零。这不表示建设免费，模型仍计建设和其他支出；但确实意味着显示的回报尚未包含一笔实际商定的项目权利收购价格。

**建议修改：**

- 第一屏分别写明“建议获取项目的方式”和“本次数字采用的投资情景”。
- 新建参考情景标注：“RTB起算；未加入实际项目权利收购报价”。
- 在运收购主要展示可支付价格、剩余寿命、合同剩余年限及给定报价下的股权回报。
- 绿地开发情景展示开发资金、失败损失、RTB转化时间；共同投资情景补充持股比例、治理权、分配安排和退出限制。
- 从市场页进入收购分析工具时，传递同一个市场、时长、收入路径和投资者类型，避免重新选择后得到另一组数字。

**验收标准：** 不展开帮助说明，读者也能判断主IRR是否包含开发风险和收购价；输入报价后，可支付价格与实际价格下的收益率可以核对。

证据：[投资模型默认阶段和价格](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/opportunities/investment.js#L32)、[全球比较](https://globalbess.vercel.app/returns)。

**P0-04：“模型固定收入”需要与“项目合同已经落实”明确分开。**

网站上方给出较高的模型固定收入比例，到了下行章节才出现“仍需收集项目合同证据”“0%模型已签约占比”。专业投资人需要知道的是：这是市场存在的机制、当前情景假设取得的合同，还是已经核查过的项目文件。

**建议使用三层表达：**

| 层次 | 读者需要理解的内容 | 建议显示 |
|---|---|---|
| 市场机制 | 该市场存在何种容量、保底或租赁安排 | 机制名称、付款方、适用条件 |
| 参考投资情景 | 模型假设能取得怎样的合同 | 首年固定比例、期限、价格、指数化、履约条件 |
| 项目证据 | 实际项目是否持有有效权利 | 已核验／待核验／未提供项目文件 |

对于市场参考情景，没有项目文件时，应优先写“未提供项目合同证据”。单独显示“0%已签约”容易被理解为已经审查一个具体项目后确认其完全无合同。

同时把合同到期、续约价格、罚则、限发处理、交易对手信用和融资接受度放在回报卡附近。相同的首年固定收入比例，并不意味着相同的融资能力。

**三、把故事线改成投资人的决策顺序**

目前市场详情的顺序大致是：论点与行动 → 电网和历史 → 收入机制 → 可融资方案 → 收益拆解 → 执行 → 特殊机会 → 下行 → 来源。宏观解释较完整，但读者到达资本投入、下行和价格判断之前，需要读较多材料。

建议采用下表顺序。深层研究仍然保留，第一层只提取改变决策的部分。

| 阅读层级 | 投资人首先要回答的问题 | 应显示的内容 |
|---|---|---|
| 30秒 | 这是什么投资，我为什么要看？ | 当前结论、具体路径、进入阶段、投资额、主回报、下行、最大否决条件 |
| 3分钟 | 为什么现在、为什么是这个市场？ | 两到三条需求与供给事实、竞争和收入压缩、下一次改变结论的事件 |
| 10分钟 | 收入和回报能否落实？ | 合同与市场化收入、成本、融资、敏感性、可支付价格 |
| 尽调 | 哪些证据到位才能投资？ | 土地、双向并网、许可、合同、设备与施工、担保、提款和收入资格 |
| 深入研究 | 数字与判断如何形成？ | 完整市场历史、方法、来源、更新记录和情景工具 |

**首页建议。** 保留一个重点市场和三个优先机会，但每张卡增加“为什么排在这里”“最大否决条件”“下一项行动”。首页应像本期投资议程，读完后能决定把研究资源放在哪两三个地方。

基金视角下，意大利排在芬兰前面可以合理；但意大利约11.6%的回报低于芬兰约14.9%，页面应直接解释排序依据。不要要求读者自己从合同期限、进入难度和融资资料中推导推荐顺序，也不应简单把排序改成IRR从高到低。

建议卡片结构：

> 意大利｜四小时容量市场项目｜RTB参考情景
> 当前判断：优先推进有合同、有并网证据的候选项目。
> 基准全股权IRR：11.6%；模型目标：9.9%；既定下行情景：2.1%。
> 收入结构：首年约20%固定收入，其余主要依赖市场化收益。
> 关键核查：合同批次、四小时折减系数，以及0.53与0.67情景下的价格上限。
> 下一步：筛选南部和海岛候选项目，取得合同与并网文件后定价。

以上是页面表达示例，数值取自本次所见基金情景。实施时应从同一模型动态生成；“优先推进”还需要相应的项目条件成立。

**市场页建议。** 第一屏放决策卡，然后顺序安排：

1. 推荐路径及备选路径的选择理由。
2. 基准／下行、目标差额、投入资本及价格上限。
3. 收入来源、合同期限和证据状态。
4. 为什么现在：系统变化、竞争供给和关键事件。
5. 执行路径、建设资金与首次收入条件。
6. 特殊机会及相对常规方案的增量价值。
7. 完整研究、来源、模型假设和观点变更。

电网地图适合放在“为什么这个位置能创造价值”处。先有需要解答的问题，再让地图提供证据。

**同一市场的多条路线应当有清晰边界。** 意大利的四小时容量市场与六至八小时MACSE、德国的纯市场化与租赁、日本的已中标LTDA与新进入者投标，都不应在同一段叙事中自然切换。

建议在市场页顶部固定“当前方案”，其他路线列为可切换的对照卡。每条路线至少对应：资格条件、时长、收入机制、成本、交付时间、价格上限及为什么选择或放弃。新闻点击应直接打开相关路线，而不只是进入该国默认页面。

**四、让全球比较真正解释取舍**

**P1-01：排序、投资建议和回报是否达标，应分别说明。**

当前比较表已经同时展示全股权、杠杆后和目标检验，这是必要的；但“优先推进／择机／观察”的决策理由仍然偏弱。

建议在选中市场的面板加入四行：

- 为什么值得投入研究资源。
- 为什么没有更高优先级。
- 触发投资所需的条件。
- 下一项事件及复核时间。

将“目标检验”增加为可复算的差额。例如：全股权回报与全股权目标差多少个百分点；杠杆后回报与对应目标差多少。爱尔兰所见约11.4%的杠杆后回报，对约11.3%的目标只有很薄余量，应显示“接近门槛”，避免一个绿色达标标签传递过强的确定性。

这不要求改动既有目标回报方法。目标的形成规则、杠杆后目标加点和边际达标的标识，应作为清楚的产品说明，并保留方法调整的人工治理流程。

**P1-02：矩阵的绿色区域与实际达标判断不一致。**

当前矩阵以固定收入比例为横轴、IRR为纵轴，绿色区域从50%固定比例和10%全股权／12%杠杆后回报开始。实际每个市场的目标回报不同，而杠杆后说明又把12%阴影称作“目标检验”。这会让颜色与表格给出不同信号。

建议二选一：

| 方案 | 展示方式 | 适用情况 |
|---|---|---|
| 推荐方案 | 纵轴改为“回报减去该投资者目标回报”；零线表示达到门槛 | 首页和配置讨论，直接比较是否有回报余量 |
| 最小修改 | 保留绝对IRR，但将10%／12%明确标为统一视觉参考线，移除达标含义 | 希望保留现有读图习惯 |

横轴明确标为“模型首年固定收入占比”，不以“收入保障”概括所有合同。选中后显示合同期限、付款方、价格调整方式及文件状态。

证据：[矩阵阈值](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/experience/charts.js#L28)、[页面的12%解释](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/experience/pages.js#L207)。

**P1-03：气泡大小要回答投入多少资本，而不是暗示市场规模。**

PR #67按典型项目建设及并网总资本开支设置气泡面积，说明已经写在图旁，这是合理的编码。但典型项目的MW和储能时长不同，因此大气泡不代表市场容量更大、可投标的更多或机会更优。

建议：

- 保留资本开支面积时，增加25／100／400百万美元等参考圆及项目MW、MWh、小时数。
- 可增加“股权投入金额”的大小选项，帮助基金判断单笔投资规模；贷款在COD才提取时，还需区分峰值股权资金与长期净股权投入。
- 16个市场使用短标签；日本三个区域等相邻点提供展开或标签避让。
- 点击点后同步突出清单行，并明确显示该点对应的投资者、路线和进入阶段。
- 若加入敏感性范围，应标注具体情景，不把人工上下行情景称作统计置信区间。

**五、把下行、融资和资金时点连接起来**

**P1-04：下行结果应在投资建议旁出现，并解释损失从哪里来。**

西澳基金情景中，基准全股权长持约13.4%，下行约-14.1%；首年税后经营现金流却只从约USD 308.6k/MW降至USD 281.8k/MW。只看首年现金流，读者无法理解整个项目回报为何下降如此之多。

这不构成模型算错的结论。它说明建设投入、长期收入、时间、合同尾部等变化没有被直观地解释。

建议展示三项互补信息：

| 内容 | 应回答的问题 |
|---|---|
| 基准／下行结果卡 | 回报、NPV、资金缺口和达到目标后的价格余量会变成什么 |
| 单因素敏感性图 | 成本、交易收入、折减系数、延期、合同结束等因素各自影响多少 |
| 组合下行桥接 | 既定组合压力怎样从基准走到下行；非线性残差单列或说明 |

杠杆后下行应沿用基准贷款条件检验，不通过在压力情景中重新缩小贷款来消除资金风险。现有模型和部分研究已重视固定基准债务安排，页面应清楚体现。

**P1-05：融资展示需要补充“何时用钱”。**

“债务占资本开支75%”不等于开工时只需准备25%的股权。现行主回报模型在COD提取项目贷款，建设期间仍由股权承担现金支出。

建议把以下指标放进融资折叠区的摘要行：

- 建设期峰值股权资金。
- COD时贷款提取及股权回收。
- 项目达到收入资格的时间。
- 贷款期限、摊还期限、到期尾款。
- 最低偿债覆盖及受限分配。
- 到期尾款或再融资缺口；与常规偿债覆盖分开显示。

现金流图分清经营现金流、股东分配、贷款提款、资本补助及税项。补助即使在投运后收到，也不宜在读者不知情的情况下混在“首年经营表现”中。

**P1-06：时间轴应体现关键依赖，减少虚假的时间精度。**

当前执行清单很具体，但4.5个月、13.5个月等整齐节点容易被理解为经核实的项目工期。常规与特殊方案还会重复一长串相同步骤，使差异反而不突出。

建议用两条共享时间轴：相同阶段合并，差异段高亮；技术／合同／市场资格／资金可采用分轨显示。至少单列：

RTB交割 → 施工与并网工程 → 送电与COD → 市场注册与资格 → 首次收入 → 实际回款。

研究中的“从场址控制开始24–48个月”与模型“从RTB交割开始18个月”可以同时成立，必须标出各自起点。确定日期、参考工期和情景假设采用不同样式。

PR #56所讨论的COD与取得收入资格间隔尚未进入本次main基线。后续可评估其中的方法与当前20年投资模型是否兼容，再整合相关展示；本评审不将该PR内容视为已上线功能。

**六、特殊机会需要解释额外价值与可支付价格**

**P1-07：更高IRR、可支付溢价和真实可执行性是三个不同判断。**

德国特殊机会的筛选假设同时包含“36个月变18个月”和“建设预算减少30%”。因此展示的回报提升不能全部解释为取得并网点、提前投运所创造的价值。来源链接也不能被理解为已证明某个具体项目能达到30%的成本下降。

建议特殊机会卡至少显示：

| 必须看到的项目 | 表达要求 |
|---|---|
| 常规与特殊方案回报 | 同一交割日、同一资本成本、同一持有口径 |
| 时间收益 | 单独改变COD／收入资格时间后的价值变化 |
| 成本收益 | 单独改变建设及改造成本后的价值变化 |
| 权利对价 | 尚未支付溢价时的回报，以及按报价支付后的回报 |
| 可支付上限 | 同时考虑目标回报与相对常规方案价值的上限 |
| 落地条件 | 可转让性、双向容量、土地、许可、工程义务及收入资格 |
| 可信程度 | 已核验、市场观察或分析假设 |

已有“相对价值上限”和“达到目标后的余量”很有用，应前置。波兰页面已经说明“尚无溢价同时通过两项检验”，这类信息应在特殊机会标题卡就能读到。

当前仅展示全股权长持IRR高于常规方案的特殊机会。这个筛选可以继续用于主推荐区，但建议加上标签“回报较优但仍未达标”，并保留可展开的备选路径。低一点IRR但显著降低峰值资本、交付风险或资金占用的方案，仍可能有投资价值；该类取舍适合单独讨论，不应只用一个回报数字替代。

证据：[德国筛选输入](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/opportunities/catalog.js#L23)、[特殊机会比较和过滤](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/opportunities/model.js)。

**七、事件日历应能改变投资行动**

**P0-05：只有月份的预测，不应显示成确定截止日。**

在2026年10月30日访问新闻页时，西澳一项预计于“2026年10月”发生的监管复审被显示为“明日截止”。现行实现把月份转换为当月最后一天，并据此倒计时。这是计算方便带来的过度确定表达。

建议事件增加“日期精度”和“日期性质”：

| 来源实际给出的信息 | 建议文案 |
|---|---|
| 法定申报截止日 | “10月30日截止，剩余X天” |
| 已公布具体会议／拍卖日期 | “11月24日举行” |
| 预计某月 | “预计10月，具体日期待确认” |
| 某季度／季节 | “预计第四季度／秋季” |
| 日期已过、结果未录入 | “预计时间已过，结果待核实” |

月份可以用于排序和内部提醒，不能自动升级为法律或项目行动截止日。建议“45天内紧急提示”同时考虑能采取什么行动：临近但无法再参与的事件，应提示“等待结果／调整判断”，而不是笼统催促进入。

证据：[新闻页](https://globalbess.vercel.app/news)、[月份转月末及倒计时逻辑](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/news/newsPage.js#L51)。

**P1-08：“相关新闻”需对应事件本身。**

线上可见的例子包括：意大利MACSE拍卖提示下关联的是光伏占地新闻；西澳容量基准和接入政策事件下关联的是阳台光伏消息。实现按市场标签匹配前两条新闻，尚未要求事件主题匹配。

建议直接相关才使用“相关新闻”；只有地理或市场相同的，改为“该市场其他动态”或不显示。更有价值的事件卡结构是：

事件与可信日期 → 影响哪条投资路线 → 改变哪个输入／条件 → 两种结果各如何行动 → 下一次复核。

页面已经有“将影响”和“落地前布局”，应继续具体化，避免大量重复“为两种结果做好准备”。日本同一全国拍卖在三个区域重复展示时，可合并成一张全国事件卡，展开东京、九州和北海道的不同影响。

新闻页标题可考虑“投资事件与动态”，让投资日历的用途更明确；行业RSS保留为第二层。

证据：[新闻关联逻辑第153行](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/news/newsPage.js#L153)。

**八、各市场应保留的主线与具体调整**

下表针对网站如何组织投资判断，不是新增市场投资推荐。相同国家的不同收入路线，应分别保留自己的模型和证据。

| 澳洲 NEM | 交付与资本市场成熟，但交易收入承压 | CIS、租赁和纯市场化分开；模型假设价格与已披露合同价格分开；节点与损耗系数前置 |

**十、辅助页面应服务于同一条决策路径**

**数据与方法。** 当前数据页很好地解释了自动获取、人工假设和观点的权限边界，但投资人还需要一张“本次数字怎么算”的简明表。建议在治理说明前加入：起算日、寿命、税费、通胀、合同指数化、衰减、增容处理、债务、退出和汇率。尤其应明确，统一按2.5%调整的比较假设不等于每个市场实际合同都具有相同指数化条款。

数据更新时间、模型假设复核时间、投资观点批准时间应分别显示。公开电价刚更新，不代表当前收入假设和投资建议也在同一时刻重新审核。电价源未发布时，模型仍有数字可以合理，但应清楚写明该数字采用的替代依据。

**深层研究。** 各国已有的“证据阶梯”“投委会门槛”“收入未公开部分”很有价值。建议从新市场页直接链接到相应段落，并在深层页面固定显示当前方案和模型口径。主页面中通用收入机制的举例和引用应优先本市场化；跨市场解释放在可展开的补充说明中。

**收购分析工具。** 作为市场详情中的“按候选项目报价测算”入口，继承当前方案。输出顺序应为：最高可支付价格 → 输入报价下的回报和资金需求 → 主要限制 → 细项假设。

**观察名单。** 保留“尚未建立完整回报模型”的边界。在全球比较提供清楚入口和升级条件，避免让没有模型的市场看起来像已完成同等深度的研究。

**变更记录。** 保留完整审计轨迹，同时增加投资人可读的“这次改动如何影响判断”。例如：某个事件发生后，收入假设、回报、推荐结论分别是否变化。无需把内部文件路径作为主要阅读内容。

**分析师工作台。** 现有工作台已经包含“引用旧引擎数字的理由”“与经济性不一致的结论”等待办类型，应优先利用这些能力。建议将重大未解决矛盾传递到受影响的页面，以“观点待复核”提示读者，并使发布流程能够识别重要口径冲突。是否阻止发布及其例外，应由分析师制定规则。

**导航。** 新版页头与数据／工具页仍有不同导航体系，应统一位置与称谓。现行通用“市场详情”入口在未处于市场页时默认指向意大利；建议改为选择市场、最近查看市场，或明确标注具体市场名。页脚应能发现方法、变更记录和分析工具，内部工作台可保持次级入口。

证据：[数据页](https://globalbess.vercel.app/data)、[导航默认目标](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/experience/chrome.js#L22)、[分析师工作台现有检查](https://github.com/jerryyuan1996/BESS-research-platform/blob/b56738e14f32d1358965bfee8af87570ecf057a8/src/desk/deskPage.js)。

**十一、建议拆分为六个可独立验收的修改包**

以下为实施顺序建议，尚未创建PR或修改网站。

| 修改包 | 目的 | 范围 | 完成标准 |
|---|---|---|---|
| 1. 数字与情景一致性 | 先恢复读者对数字的信任 | 静态旧IRR、芬兰固定占比、进入阶段／新建标签、默认对价说明、统一情景标识 | 同一情景跨页面、图表、导出可对账；旧口径均明确归档 |
| 2. 首页与市场页决策摘要 | 让读者迅速知道为什么看、什么条件下投 | 推荐理由、排序解释、下行前置、投资否决条件、下一步行动 | 30秒内可复述当前方案、资本、风险和动作 |
| 3. 比较矩阵与风险表达 | 让图表对应实际投资判断 | 目标差额／参考线、合同期限与证据、气泡标尺、标签、压力情景 | 图的颜色、表格检验、投资者类型切换不相互矛盾 |
| 4. 执行与特殊机会 | 解释增量价值及资金路径 | 共享时间轴、COD至收入资格、峰值股权、成本／时间价值拆解、报价前后回报 | 能回答多花多少钱、买到什么优势、何时回款及何时不值得买 |
| 5. 投资事件与观点更新 | 把新闻转化为可核实的行动 | 日期精度、事件相关性、路线直达、事件结果与观点复核 | 月份不再生成虚假截止日；事件能对应具体方案及决策条件 |
| 6. 全站阅读体验 | 降低使用负担 | 统一导航、术语、单位、字号、对比度、移动与打印 | 关键路径连贯；手机和打印保留投资条件与来源 |

建议先完成第1包，再推进第2–5包，最后统一打磨第6包。涉及排序、目标回报方法、合同假设和推荐结论的实质变化，应单独审阅其投资依据，避免在视觉调整中不知不觉改变方法论。

**建议的验收场景。**

- 四类投资者切换后，主张、方案、阶段、指标和下一步行动一致。
- 16个市场及所有已提供的收入路线，当前数字均能追溯至同一情景。
- 芬兰首年固定比例与收入金额复算一致；合同期限变化能在全寿命图中体现。
- 意大利容量市场与MACSE、德国租赁与纯市场化、日本LTDA中标资产与新进入方案不串用论点。
- 一个项目全股权未达标、杠杆后勉强达标时，界面准确显示两项检验和余量。
- 一项特殊机会优于常规但仍未达标时，界面不会暗示可以支付溢价。
- 输入实际收购报价后，价格上限、NPV、全股权与杠杆后回报一起更新。
- COD延迟、收入资格延迟、补助到账延迟分别影响相应现金流。
- 已定具体截止日、只有月份、日期未定、已过期待核实四类事件文案不同。
- 新闻仅同市场但不直接相关时，不标为该事件的相关新闻。
- 基准与下行使用相同债务安排检验，清楚显示尾款或资金缺口。
- 1366×768与常见手机宽度下，重要条件可读、按钮可用、图表不丢关键信息。
- 打印和导出保留日期、投资者类型、情景、币种、进入阶段、关键假设与来源。

**十三、PR #68更新复核与本轮实施**

PR #68新增西班牙和沙特，将覆盖范围从16个市场扩至18个；其中17个有可计算的参考投资回报，沙特因SSA付费未公开而暂不定价。可计算、已完成投资评级、具备项目合同证据，是三个不同状态。原有英国和东京的资产回报评级调整已按PR #68保留，本轮没有重新设定市场评分或改写推荐排序。

| 新增发现 | 专业投资人的解读 | 修改建议与本轮处理 |
|---|---|---|
| 西班牙PR说明给出2.58%，基金视角当前20年税后RTB模型约4.06% | 两组模型口径不同，不能解读为收入预测自然改善 | 当前页面论点改为从所选投资模型生成；历史口径保留明确说明 |
| 西班牙使用完全预见日前交易参考值，并借用机组增长曲线 | 未计容量／平衡收入不等于当前测算天然保守，执行折损也可能压低实现收入 | 第一层显示交易测算局限、迁移曲线和排除项；补齐未评级但可测算市场的下行情景 |
| 沙特合同存在但付费未公布 | 价格未知不应被归类成经济性很差；也不能以估计价格填补 | 单列“暂不能测算”；给出所需合同证据；避免进入无定价能力的分析工具和长期加载状态 |
| 沙特反求付费采用研究中的参考折现率，且项目税务和汇出安排尚未闭合 | 盈亏平衡付费不是实际中标价，也不等于特定投资者的完整股权目标 | 保留为深层研究与资料缺口；实际报价必须取得SSA、股权及税务资料后重算 |
| 新市场已进入核心清单，但尚无与老市场相同的完整观点事件记录 | 覆盖数、已定价数和已批准投资结论数应分开 | 首页显示18个覆盖／17个可测算／1个暂不能测算；保持新市场“继续研究”的判断状态 |
| 新市场缺少共用投资卡的国家轮廓 | 新市场视觉层级不完整 | 增加西班牙、沙特本地矢量轮廓，与其余市场一致 |
| 新市场事件在研究章节中的自然语言尚未全部转成日历记录 | 不能把预计拍卖或二手消息直接升级成确定日期 | 列为后续资料维护项：先核实官方事件、日期精度和来源，再进入观点事件库 |

本轮实现覆盖六个修改包中可以依照既有模型和已发布材料完成的展示、计算衔接与交互。涉及实际合同、法务税务、市场执行折损和新事件来源核验的研究资料，继续作为投资条件显示。

| 修改包 | 本轮实现 |
|---|---|
| 数字与情景一致性 | 自动生成当前模型论点；修复芬兰固定比例；展示RTB、20年、税后名义及默认权利对价；区分推荐获取方式与测算起点 |
| 决策摘要与排序解释 | 市场页前置基准、下行、目标余量、峰值股权、价格上限、既有判断依据及核查条件；保留已批准的排序 |
| 跨市场图表 | 纵轴改为各市场回报减对应投资者目标；固定首年比例注明适用边界；气泡金额标尺、短标签和选择反馈；手机清单改为可读卡片 |
| 风险、资金与执行 | 单因素敏感性；用基准贷款检验下行杠杆回报、含尾款覆盖和年度偿债缺口；20年收入结构；建设期峰值股权及COD提款；共同时间段合并 |
| 特殊机会与新闻 | 设计、时间、成本和报价的顺序NPV桥接；相对改善但仍未达标的提示；月份不再生成虚构截止日；同市场新闻准确标名；事件链接定位对应路线 |
| 导航与可信度 | 工具页与数据页增加统一导航；取消通用市场入口默认进入意大利；展示比较模型与合同条款的区别、观点复核日期；深层研究标明历史口径；改善首屏与文字对比 |
