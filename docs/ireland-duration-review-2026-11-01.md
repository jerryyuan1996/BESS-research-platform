# 爱尔兰：较长时长能增加多少回报？

2026年11月1日，Australia/Perth。状态：分析师已在聊天中明确批准“六小时候选＋保持观察，并记录历史”；随后实施数值、推荐及追加式历史更新。辅助服务保留原假设。

## 结论

在平台已有且可测算的四、六、八小时容量方案中，**六小时回报最高，但仍明显低于目标**。与更新容量认定后的四小时相比，六小时全股权长持IRR高 **0.45个百分点**，同时50 MW项目总建设投入增加约 **EUR19.70m**。八小时回报反而低于六小时。建议把六小时列为继续核价的候选，市场判断改为“保持观察”，不继续以原“提前布局”结论推进入场。

原四小时模型在66%示例容量认定下，页面全股权长持IRR为9.10%、设计长持IRR为9.00%。更新后的六小时4.43%不能与旧四小时9.10%解释为时长本身导致的变化：容量认定假设同时发生了纠正。

## 建议及其限制

1. 如分析师批准，将研究候选时长改为六小时，并把基础设施基金建议改为“保持观察”：先核实合同批次、实际价格及每新增MWh的造价，再决定是否入场。
2. 六小时是在这些可测算时长中IRR最高；平台的既定时长排序依据每MW价值，一小时反而是“亏损最少”的容量设计，但全部时长价值均为负。因此不能把六小时写成平台按每MW价值自动选出的最优方案，也不能把一小时写成值得投资。
3. 当前商贸捕获及成本设计网格支持到八小时。十二小时虽有官方容量认定点，但缺少获批的批发捕获曲线假设；本次不外推一个十二小时回报。
4. 已有旧拍卖合同按其本身价格、认定比例和交付义务单独定价；本次基准不追溯改变已持有合同的权利。
