# 修改建议与本轮落实记录

日期：2026-10-30。基线：PR #69 合并后 main 80843a2。以下四项按本次用户确认执行，覆盖早期评审中关于矩阵“减目标”和把下行提前的建议。历次评审证据保留在 [投资人评审](investor-review-2026-10-30.md)。

## 1. 全球机会矩阵

- 矩阵占满内容宽度，当前市场摘要放在图表下方；投资依据、合同证据与项目参数可展开查看。
- 纵轴直接显示全股权或杠杆后股权 IRR，单位为百分比。不使用统一回报门槛改变坐标，也不画“达标”背景区。
- 横轴继续使用模型首年固定收入比例；圆点继续按项目总建设及并网资本开支的美元面积比例绘制。
- 手机端图表可横向滚动，市场摘要适应屏幕宽度。

## 2. 下行条件与历史频率

- 下行风险整体移至“研究与来源”正上方。
- 用有效模型输入解释延期、建设预算上涨、固定价下降、固定价期缩短、交易收入下降与运维成本增加。已被其他约束覆盖的工期输入不描述为实际延期。
- 压力测试同时使用多项不利假设。首年现金流与全生命周期 IRR 可能因建设和合同期限差异而呈现不同幅度的变化。
- 有公开价格样本的西澳、波兰及日本三个区域，统计“月均日价差环比降幅至少达到模型交易相关收入降幅”的历史次数与频率。价差是价格压力代理，不等同于 BESS 实际收益。
- 只使用快照日期之前的完整自然月，且每月至少90%日价差有效；只比较连续月份。展示分子、分母、区间、代理时长、快照日期及原始官方来源。
- 此短期样本的历史频率不作为未来概率，也不作为造价、工期、签约共同恶化的联合概率。缺少足够样本的市场明确显示暂不能可靠估计，不填造“10%/20%”等概率。

## 3. 逐步执行指南与月度现金流

- 时间表位于左侧，逐月净现金与累计净现金图位于右侧；手机上依次排列。
- 仅在特殊机会有效时提供常规／特殊方案开关；时间表、全生命周期图与后续现金流随同一个选择更新，语言切换保留方案选择。
- 图表统一采用与主全股权 IRR 相同的20年长持、税后名义口径及全项目原币金额。模型中建设、回款、税费、再投资和期末退役支出全部保留。
- 每个自然月都有一格。模型原有的年度经营净现金仍保留在运营年末结算，未虚构月度季节性；无收付月份显示零。小数月份归入所在月份，原始日期与金额可展开核查。
- 累计曲线单独设置纵轴，避免建设大额流出掩盖后续回收方向。图表支持点击和键盘滑块选择月份。
- “后续经营及退出现金流”默认收起，展开后使用相同图形，沿用当前方案及从交割起的累计余额。
- 图表只展示模型结果，不修改收入预测、税费规则、回报率或投资排序。

## 4. 研究背景弹窗

- “市场投资判断”中的“电网、历史与完整研究背景”打开独立对话窗口。
- 保留完整研究内容，按需载入；窗口内可滚动。
- 右上角关闭、Esc及点击遮罩均可关闭；关闭后回到原页面位置，键盘焦点返回打开按钮。
