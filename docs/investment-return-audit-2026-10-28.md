# Investment-return reconciliation — 28 October 2026

The website now uses one RTB-close, 20-operating-year, nominal after-project-tax acquisition case. Pre-operation funding is all cash. Headline, global comparison, market detail and the default conventional column publish the same lower-of-hold-and-sale return. Target return is a hurdle, not the calculated IRR.

The old Italian 14.6% was a rounded 15-year before-project-tax operating-model hold IRR. Its new infrastructure-fund reference is approximately 9.6%, including the construction calendar, tax, contingencies, fees and sale policy. Legacy engine fixtures are retained as an operating-model calculation check.

Two implementation issues were corrected: route/duration-specific capacity pricing options now reach the acquisition adapter, and special designs are repriced at their actual duration before applying cost differences. In particular, an eight-hour MACSE alternative no longer inherits a four-hour construction budget.

Capex below includes remaining construction, grid and reference contingency, excluding acquisition consideration, recoverable VAT and capital support. T+0 is investment closing / first capital commitment. N/M means the cash-flow solver does not provide a unique IRR. No number is substituted for that outcome.
