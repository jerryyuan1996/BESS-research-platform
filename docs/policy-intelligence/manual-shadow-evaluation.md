# Manual shadow evaluation: disabled prototype

The separate `scripts/policy/evaluate-shadow.mjs` entry currently reports disabled and does not read a credential, invoke a provider or write public data. `policy/manual-evaluation.mjs` supplies an isolated, injected-transport case runner; its corpus gate requires twelve distinct independently labelled cases, all four pilot markets, source-body hash matches, source/rights/translation review and a reviewer identity. Expected labels and reviewer names are not passed to the model. The existing bounded shadow runner supplies input/output/time/cost checks and produces no publisher authority. An independent confidentiality callback must approve evidence before invocation, and an independent semantic callback must approve the candidate before a result is counted.

This resolves the schema-level circular dependency for a *labelled* corpus: the isolated evaluator may invoke the shadow validator before model accuracy exists, without changing the production activation gate. No real corpus is approved. The existing date-boundary diagnostic is not a model evaluation or independent legal review.

The new `manual-evaluation-runner.mjs` wires the original fingerprint-verified confidentiality scanner, the existing independent semantic validator and a pre-invocation exclusive daily reservation on a fixed ignored local path. A reservation survives a timeout or unknown outcome and rejects duplicate days/case IDs, a thirteenth call, excess estimated token cost, malformed ledger entries and symbolic audit paths. The runner has no investment or publisher writer. Tests use injected fake transports; no actual provider is contacted.

Before real use, the execution environment still needs an approved, genuinely persistent, access-controlled audit store. An ephemeral Actions runner or evictable cache is insufficient: deletion or loss of the local ledger would lose its audit history. A separately reviewed integration must bind the approved corpus, read-only credentials and durable audit to the disconnected command entry. Concrete model/cost authorization, source profiles and human-reviewed labels remain absent. The current entry therefore cannot run a paid evaluation. Do not activate production or alter the production gold-case gate to make it run.

Open source-review items: DE official final status and document-specific rights; GB Gate 2 current revisions and OGL attribution; NEM later amendments, source rights and implementation timing; WA individual commencement notices, scope and gazette rights. Each case needs its original byte hash, as-of date, locator, expected label, reviewer and bilingual meaning review. Access denial must not be bypassed.
