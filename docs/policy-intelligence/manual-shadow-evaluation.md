The separate `scripts/policy/evaluate-shadow.mjs --case <approved-id> --request <request-id>` entry defaults to disabled and reads no credential, invokes no provider and writes no public data. A separate committed `MANUAL_EVALUATION_AUTHORIZATION` must pin the complete reviewed corpus hash. Expected labels and reviewer names are not passed to the model. An original fingerprint-verified confidentiality scan precedes invocation, and independent semantics precede counting a result. No result grants publisher authority.

This resolves the schema-level circular dependency for a *labelled* corpus: the isolated evaluator may invoke the shadow validator before model accuracy exists, without changing the production activation gate. No real corpus is approved. The existing date-boundary diagnostic is not a model evaluation or independent legal review.

The new `manual-evaluation-runner.mjs` wires the original fingerprint-verified confidentiality scanner, the existing independent semantic validator and a pre-invocation exclusive daily reservation on a fixed ignored local path. A reservation survives a timeout or unknown outcome and rejects duplicate days/case IDs, a thirteenth call, excess estimated token cost, malformed ledger entries and symbolic audit paths. The runner has no investment or publisher writer. Tests use injected fake transports; no actual provider is contacted.

Before real use, the execution environment still needs an approved, genuinely persistent, access-controlled local audit store. An ephemeral Actions runner or evictable cache is insufficient: deletion or loss of the ledger would lose its audit history. The command now binds the approved corpus, source profiles, dedicated credential and durable runner. The fixed audit directory is `etl/out/policy-evaluation-ledger`; immutable daily reservations remain after uncertain outcomes, and a separate exclusive daily result records case/source hashes, attempt count, status and validated token/cost usage, without evidence text or reviewer identity. Concrete model/cost authorization, source profiles, human-reviewed labels and host/audit approval remain absent. The entry therefore cannot run a paid evaluation today. Do not activate production or alter the production gold-case gate to make it run.

## Offline protocol repair, 7 November 2026

The [provider specification](https://platform.claude.com/docs/en/build-with-claude/structured-outputs) excludes string `maxLength` and array bounds beyond `minItems` 0/1. Raw `messages.create` does not supply the SDK helper transformation. This was a protocol incompatibility, not an observed paid failure.

`model-contract.mjs` now derives a wire schema without those keywords, retaining required fields, enums and closed objects, with local bounds described as instructions. A shared nullable definition avoids repeated union definitions: the serialized schema has five `anyOf` nodes. Provider grammar compilation and actual acceptance remain unmeasured; offline shape checks cannot guarantee internal complexity acceptance. Independent local structural validation enforces the original required/type/array/quote contract before the existing evidence, reference, history, translation and rights checks. Mocks inspect the actual SDK request and reject malformed responses. All model, paid-evaluation and automatic-publication controls remain OFF.

Offline serialization measured 14,648 bytes with the published 18-instrument prior summary, empty evidence and the existing margin; the previous unsupported raw schema required 14,185 bytes. These are local byte measurements with a synthetic model identity, not provider token counts. At that checkpoint the single input field was increased to **16,000 instead of 12,000** following the size-only decision. That field conflated bytes and tokens; the 10 November repair above supersedes it with 16,000 bytes and the original 12,000-token budget. Evidence is not compressed to fit. The 3,000-output-token ceiling, time limit, USD controls, source restrictions and OFF switches are unchanged. Reservations now use only the separate unchanged token ceiling and reject an insufficient budget before invocation; no paid use is authorized. Provider-injected overhead remains unmeasured.
