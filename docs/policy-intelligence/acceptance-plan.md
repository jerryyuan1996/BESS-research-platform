# P1-D acceptance plan

One integration branch, logical scoped checkpoints, one consolidated draft release PR after local gates. No per-fix push churn. All release checks run on the PR's exact commit and on the final publication artifact.

| Phase | Required evidence |
|---|---|
| D0 | Actual source/import audit, authority map, billing limitations, forecast, design and release decision |
| D1 | Strict schemas, legal/date/number/evidence validation, immutable replay, independent fail-closed writer and read-only resolver |
| D2 | Offline official discovery fixtures, redirects/digests/rights/robots, one daily scheduler, unchanged/failure/retry tests |
| D3 | Shadow-only extraction packets, hostile-source tests, 12+ gold cases, honest empirical metrics and no paid activation |
| D4 | Coupled map/feed, filters/preview/history, mobile/keyboard/EN-ZH, lazy route and measured performance |
| D5 | Evidence-rich dossier, stable versions/diffs, guided/Explorer scenes, hostile scene rejection, sidecar without view mutation |
| D6 DE | Fresh primary BKZ/AgNes evidence, separate source and content review |
| D6 GB | Fresh primary connections/capacity evidence, separate review |
| D6 NEM | Fresh primary NEM/FCAS/CIS applicability, separate review |
| D6 WA | Fresh primary WEM/RCM/ESS evidence, separate review |
| D7 | Compatibility-first comparisons and shared market adapter, unchanged seven tabs and P1 lazy graphs |
| D8 | Single publisher, least privilege, real model authorization or OFF, source review, rollback, measured cycle/budget and release readiness |

Gold matrix minimum: draft, consultation, amendment, adoption, delayed effect, effective, withdrawn, repealed/superseded, conflicting sources, dead URL, misleading headline, revised official figure, material view discrepancy, translation mismatch, fake locator, prompt injection and outages. Synthetic safety fixtures prove code behavior only; they do not prove historical source accuracy or model quality. Keep the two evaluations separate.

Integration gates: `npm test`, `npm run test:current`, `npm run build`, `npm run test:budget`, `npm run test:e2e`, `npm run etl:verify`, original staged scan and built confidentiality scan with required marker/output flags. Do not regenerate approved baselines. Reproduce reported GB static-fingerprint/dynamic-projection mismatch; repair the test boundary with substantive runtime projection coverage, not a fixture rewrite.

Release gates: all pilots source-reviewed, zero unsupported definitive status/date/number claims, original retrievable locators on every critical claim, bilingual semantic review, no unauthorized financial/view/story changes, no confidentiality/rights violation, exact-artifact scan, real GitHub statuses, production identity/readiness and smoke evidence. If any gate remains unverified, report blocked and leave production model OFF. A local build or synthetic cycle is never production verification.
