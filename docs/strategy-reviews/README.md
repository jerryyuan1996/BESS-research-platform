# Strategy review decision log

Full public reports are stored in one directory per review. The bulky reproducible packet remains in ignored `etl/out/strategy-review/`. Reports must pass the confidentiality scan before commit. Analysis, decision, apply and release are separate statuses. A decision records only the proposal ids explicitly selected by the analyst. An approved assumption still requires its written plan and separate sign-off; it is not automatically implemented.
