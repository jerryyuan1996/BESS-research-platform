# Global BESS 三页设计与交互说明

完成日期：2026-10-26。设计对象：投资简报、全球市场比较、市场详情。提供中英双语，沿用平台16个市场及4类投资者视角。

## 1. 整体信息架构

三页分别回答「先投哪里」「为什么选它」「如何落实」。主导航始终保留投资简报、全球市场、市场详情；详情页另有章节导航及市场切换。

| 页面 | 路径 | 核心内容 | 主要下一步 |
| --- | --- | --- | --- |
| 投资简报 | `/` | 一句投资建议、一个重点方案、两个首屏指标、三个优先机会、三步决策路径 | 直接进入推荐市场，或查看全球比较 |
| 全球市场 | `/returns` | Global opportunity matrix、16市场清单、地区/搜索/排序、最多3市场并排比较 | 点击矩阵、表格或比较卡进入具体市场 |
| 市场详情 | `/markets/:slug` | 市场判断、bankable case、现金流、收益拆解、操作步骤、下行风险、来源 | 打开原有深入研究，或带着当前市场返回全球比较 |

主路径：**首页投资结论 → 全球矩阵筛选 → 市场详情与执行方案 → 返回全球比较**。熟悉市场的用户可从首页推荐卡直接进入第三页。原有研究标签页、Investment Lab、数据和市场动态保留，作为下一层研究入口。

地区、搜索、排序、比较名单写入地址参数，刷新仍可恢复。投资者视角与语言使用平台原有状态，跨页保持一致。详情页的「返回全球比较」预选当前市场；浏览器返回可恢复之前的筛选地址。

## 2. 三页内容与参考图的关系

### 首页：少量指标，先给出判断

参考01的留白、编辑式标题、重点投资卡与分段节奏。首屏只展示推荐方案的无杠杆持有期IRR和模型固定收入占比，并以15年经营现金流小图辅助阅读。下面保留三项优先机会、决策路径和行动入口。

首页不放what-if控件、前置条件免责声明或密集参数表。推荐次序来自仓库既有投资判断，按投资者视角选择方案，并非简单按照IRR最高排序。没有使用附件中的伦敦或EAPI示例数值。

### 全球比较：量化筛选与清晰下钻

参考02的矩阵、机会清单与收入质量表达，统一改为浅色编辑式界面。横轴采用仓库可验证的模型固定收入占比，纵轴采用无杠杆持有期IRR；颜色配合文字表达投资动作。没有为了复刻参考图而虚构气候评分。

矩阵支持点击、Enter和空格选择，旁侧卡片同步展示方案。下方清单支持地区筛选、中英文市场搜索、投资优先级/回报/固定占比排序。最多勾选3项并排比较，超出上限有提示；无结果可一键重置。弹窗可通过Esc关闭并回到触发按钮。

统一比较的是15年无杠杆框架及美元/MW金额，保留各市场实际推荐时长、收入路径和补助口径。表格明确展示时长；固定收入占比不混同于项目已签合同。

### 市场详情：从研究观点到可执行方案

参考03的银行融资视角与现金流桥接，形成六个连续章节：

1. **市场概览**：既有投资判断及下一项投资行动，可继续阅读完整研究。
2. **Bankable case**：IRR、固定收入占比、最低DSCR、净投资额；年度基准/下行经营现金流与偿债支付图。
3. **收益breakdown**：固定收入、续约收入、交易及辅助服务、设备服务成本、其他成本和经营现金流瀑布图，附精确数值。
4. **Step-by-step operation guidance**：锁定资产与并网权利、落实收入路径、确定设计预算融资、调试准入运营。每一步列负责人、工作内容和交付物，并补充本市场核查项。
5. **Downside risk**：基准与仓库既定不利输入边界的对比，展开可见输入；同时解释收入兑现、交付和债务到期风险。
6. **来源**：数据日期、模型版本、简报日期、外部来源以及原有深入研究入口。

西澳、英国、芬兰、罗马尼亚已有本地建设路径，按需加载其阶段、依赖关系和时间依据；没有将可并行的工作简单拼成总工期，也没有为其他市场编造审批时长。这里的bankable case是承销分析组织方式，页面不宣称已获得银行批准。

## 3. 统一风格的落实

| 元素 | 统一规则 |
| --- | --- |
| 背景与重点区 | 米白 `#f5f3ed`、近白面板 `#fffefa`、深绿 `#224e40` |
| 文字与辅助色 | 深绿墨色 `#193c32`、浅青柠 `#dce6b7`；金色用于择机，铜色用于下行风险 |
| 字体 | 系统衬线用于标题；系统无衬线用于正文、控件；等宽样式用于元信息；数字用等宽数字排列 |
| 组件 | 共用页头、页脚、标题、按钮、指标、状态标签、卡片、来源和图表语义 |
| 设计规范 | 字号、字重、圆角接入现有tokens；新增集中定义的展示字号；继续使用720/900/1050响应式分界 |
| 视觉层次 | 首页留白更多，第二页加密比较，第三页按章节深入；同一颜色持续表达同一含义 |
| 交互 | 清晰焦点轮廓、原生选择与复选框、可键盘操作矩阵、折叠详情、减少动态效果偏好支持 |

手机端改为单列、折叠菜单、双列指标，宽表格在组件内滚动；矩阵、现金流和瀑布图保留可读尺寸并提示横向查看，下行表格改为分组数值。原有市场研究页也接入相同页头、页脚及基础配色。

## 4. 数据与实现边界

- `src/experience/model.js`连接既有简报、经济模型和债务模型，不重写投资排序或计算引擎。
- 同一市场在三页采用相同收入路径、时长和补助口径，避免首页和详情数值不一致。
- 交易收入已经包含辅助服务；`svcY`是设备服务成本，瀑布图单独扣除，防止收入重复计算。
- 下行现金流保留基准债务安排及到期本金，防止重新缩减债务掩盖融资风险。
- 确定性下行情景明确区别于P90概率预测；定期偿债DSCR与含到期本金覆盖率分开标注。
- 既有深层研究路由保留；新增页面和本地建设路径按需加载，原有首页与入口包体预算保持不变。
- 页面数据沿用仓库当前模型，不把参考图片的演示数据写成市场事实。
